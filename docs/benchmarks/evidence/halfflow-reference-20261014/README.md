# HalfFlow reference audit evidence

See [the audit report](../../halfflow-reference-audit-v1.md) for interpretation
and [artifact-manifest.json](artifact-manifest.json) for exact artifact identities.
This archive contains derived scientific summaries and program source, not
source MRI volumes or anatomical label volumes. Large artifacts remain in the
ignored local study and are represented by hashes and sizes.

Anatomical annotations derive from Mindboggle-101. Attribution: Arno Klein and
Jason Tourville, *101 labeled brain images and a consistent human cortical
labeling protocol*, Frontiers in Brain Imaging Methods 6:171 (2012),
[doi:10.3389/fnins.2012.00171](https://doi.org/10.3389/fnins.2012.00171).
The cortical label release uses CC BY 4.0; source OASIS MRI access remains
subject to its original terms. No permission to redistribute source images is
implied by this evidence archive. Program source follows the repository license.

The original plot and summary are retained alongside the reviewed figure and
final summary. Presentation changes did not change measurements or selection.
Unused freezes and the failed macOS timing wrapper are retained explicitly.
None of these development results is a qualification claim.
